    Pair a peer
    1. On the first device, create an offer and copy your pairing data to your peer.
    2. On the second device, paste the offer and select Accept offer. This opens the shared note and creates an answer.
    3. Send that answer back. On the first device, paste it and select Accept answer.

    No discovery or relay service. Direct connections generally need the same local network; some browser and network configurations block pairing. Keep pairing data private. Reconnect by exchanging a fresh offer and answer.
